For developers

How the checkout works

Three server-side steps between “Add to bag” and a paid order. The browser never sees a credential.

  1. 01

    A session is created server-side

    Your server signs the order line items and asks Hamro Pay for a checkout session. API keys and signing secrets stay on the server.

  2. 02

    The customer pays on Hamro Pay

    The browser is handed to Hamro Pay's hosted page for mobile banking, internet banking, QR or connectIPS. Card and wallet details never touch this store.

  3. 03

    Payment is verified before fulfilment

    When the customer returns — or a signed webhook arrives — your server asks Hamro Pay for the authoritative status and only then marks the order paid.
